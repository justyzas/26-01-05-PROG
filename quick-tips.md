## Greitosios mygtukų kombinacijos

- **CTRL+S** - Išsaugo šiuo metu redaguojamą failą
- **CTRL+C** - Nukopijuoja pažymėtą teksto segmentą
- **CTRL+V** - Įklijuoja nukopijuotą teksto segmentą
- **CTRL+Z** - Atstato kodą/veiksmus atgal per vieną žingsnį
- **CTRL+Y** - Atstato atstatymą (Atvirkštinis veiksmas `CTRL+Z`)
- **CTRL+D** - Pasirinkus tokį patį tekstą ir paspaudinėjus šią kombinaciją galima greitai redaguoti panašius elementus
- **CTRL+/** - Pasirinkus teksto segmentą, arba padėjus žymeklį ant tam tikros eilutės, užkomentuoja tekstą
- **CTRL+SPACE** - Pažymėjus dabartinį teksto vedimą tam tikroje padėtyje pateikia pasiūlymus, kas ten glai būti įrašoma
- **SHIFT+ALT+DOWN** - Dublikuoja tokią pačią eilutę į apačią

NODE komandos:

`node path/to.js` - JS programos paleidimas per NodeJS
`node -v` - Node versijos patikrinimas
`npm -v` - Node Package Manager versijos patikrinimas

`npm init -y` - Sukuria pradinę projekto konfiguraciją

### Paketų tvarkymas

`npm install` - įrašo numatytus package.json faile modulius
`npm install paketas` - įrašo modulį pagal pavadinimą
`npm uninstall paketas` - ištrina jau įrašytą modulį

### UNIX komandos:

`cd path/to/destination/folder` - change directory
`cd ..` - pereiti į ankstesnį aplanką
