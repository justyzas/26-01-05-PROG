# 🌐 Interneto svetainių kūrimo ir JavaScript pagrindų kursas

## Kurso įvadas

Šis kursas skirtas **pradedantiesiems**, norintiems suprasti, kaip veikia internetas ir kaip kuriamos modernios interneto svetainės bei aplikacijos. Per 8 savaites studentai nuosekliai pereis nuo pagrindinių HTML ir CSS žinių iki interaktyvių sprendimų su JavaScript, NodeJS, React bei duomenų bazėmis.

Kursas orientuotas į **praktinius įgūdžius** – kiekviena tema bus įtvirtinama realiomis užduotimis, o kurso pabaigoje studentai sukurs veikiantį mini projektą.

---

## 🎯 Kurso tikslas

Suteikti studentams tvirtus interneto technologijų pagrindus, leidžiančius:

- suprasti, kaip veikia internetas ir naršyklės,
- kurti struktūruotas ir semantiškas HTML svetaines,
- stilizuoti puslapius naudojant CSS,
- pridėti interaktyvumą su JavaScript,
- suprasti serverių veikimą ir Node.js pagrindus,
- susipažinti su React biblioteka,
- suprasti duomenų bazių veikimą ir CRUD operacijas.

---

## 👩‍💻 Kam skirtas šis kursas?

Kursas skirtas:

- studentams be programavimo patirties,
- norintiems pradėti karjerą IT srityje,
- siekiantiems suprasti, kaip kuriamos interneto svetainės,
- planuojantiems toliau mokytis frontend arba full-stack programavimo.

---

## 🧩 Kurso struktūra

- **Trukmė:** 8 savaitės
- **Užsiėmimai:** 3 kartus per savaitę po 3 valandas
- **Iš viso:** 72 akademinės valandos
- **Mokymosi forma:** teorija + praktika + projektinis darbas

Kiekviena savaitė skirta konkrečiai temų grupei, palaipsniui didinant sudėtingumą ir jungiant žinias tarpusavyje.
